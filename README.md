## 📚 Lab Experiments & Observation Manual

Complete lab experiments for Day-1 covering search algorithms, classical AI problems, and game/problem-solving agents implemented in Python 3.11 with step-by-step algorithms, source code, and verified IDLE compiler outputs.

### 📅 Part 1: Experiments Assigned for 13.10.2026
1. [**8-Puzzle Problem**](Lab%20Experiments/Exp1_8_Puzzle.py) (CO1) — Solved using A* Search with Manhattan Distance Heuristic.
2. [**8-Queen Problem**](Lab%20Experiments/Exp2_8_Queen.py) (CO1) — Solved using Backtracking Algorithm on an 8x8 chessboard.
3. [**Water Jug Problem**](Lab%20Experiments/Exp3_Water_Jug.py) (CO2) — Solved using Breadth-First State Space Search.
4. [**Missionaries and Cannibals Problem**](Lab%20Experiments/Exp4_Missionaries_Cannibals.py) (CO3) — Solved using Breadth-First State Space Search.
5. [**Vacuum Cleaner Agent (Vacuum World)**](Lab%20Experiments/Exp5_Vacuum_Cleaner.py) (CO3) — Reflex agent implementation in a 2-room environment.

### 📅 Part 2: Experiments Assigned for 15.10.2026
6. [**Breadth First Search (BFS)**](Lab%20Experiments/Exp6_BFS.py) (CO3) — Graph traversal using FIFO Queue and shortest path finder.
7. [**Depth First Search (DFS)**](Lab%20Experiments/Exp7_DFS.py) (CO4) — Graph traversal using Recursive call stack and LIFO Stack.
8. [**A\* Search Algorithm**](Lab%20Experiments/Exp8_A_Star.py) (CO4) — Optimal path finding on weighted graphs with heuristic estimates $f(n) = g(n) + h(n)$.

### 📘 Additional Day-1 Syllabus Experiments
